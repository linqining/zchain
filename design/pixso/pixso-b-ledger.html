17证明中心proofs
Design System

方向 B 是什么:一本可被审计的账簿

ThesisDS-0

方向 A(毡布绿)把钱包做成牌桌:夜色、毡布、发光翡翠、圆角胶囊,情绪是「上桌」。方向 B 把钱包做成账簿:纸白、细线账格、方形印章、等宽数字右对齐,情绪是「对账」。产品的真实差异点不是牌桌——牌桌是竞品都有的——而是结算可证。所以方向 B 把 finality 状态从二级页面提成一等公民组件(凭证条),出现在每一个涉及资产变动的位置。

维度方向 A · 毡布绿 v0.1方向 B · 账簿 v0.2为什么换
底色青黑毡布 #070d0a纸白 #f5f2ea(可切夜场)账簿语义;强光/桌面环境下可读
容器填充卡 + 渐变 + 8–20px 圆角细线账格 + 3px 圆角 + 1px hairline减少「卡片套卡片」的层级噪声
标签胶囊 pill方形 chip + 等宽大字距印刷票据上的分类戳,不是营销徽章
导航底部 4 tab(首页 + 三条链)底部 3 tab(总账 / 账簿 / 证明)+ 链=顶部切换器链是筛选器,不是目的地;消除首页与链页的重复
链页实现zc / evm / stk 三套独立模板一个「账簿」模板 × 三个 pane,换数据不换结构直接消灭 popup.js 里 EVM/Starknet 的复制粘贴
finality提现页一个 dot 行 + 回执列表 chip凭证条组件,凡资产变动处必现「可证」是这个产品唯一不可复制的资产
状态强调颜色 + 发光感印章(旋转 −4°)+ 反色块品牌纪律:不用描边字/发光字
数字等宽,左对齐为主等宽 + tabular-nums,右对齐成列账簿的对齐纪律:小数点必须能竖着读

双底色与对比度

ColorDS-1

两套底色共用同一组语义角色变量,屏幕代码不含任何硬编码色值——切底色即换皮。夜场底的 14 个 token 逐字抄自 website/media-kit/v0.1/brand.css(--bg→--pg #070d0a、--surface→--cd #101c15、--text→--ink #f0f7f1、--felt #37e39c、--real #ffc75a … 一个字节未改);只有 --ink-3 #7d9a8b 与 --amb #ffd166 是本稿新增,因为品牌表里没有第三级文本色、也没有 amber;-w / -rl 后缀是给原色加 alpha 得到的底纹与描边,属派生而非改动。纸白底则是把品牌翡翠/天蓝/暖金压深成「墨」,以在浅底上达到印刷级对比。工具条上「纸白底 / 夜场底」按钮可实时切换整份设计稿。
