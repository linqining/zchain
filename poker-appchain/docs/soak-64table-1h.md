## 4. 口径与边界（如实标注）

1. **证明引擎为 host-validate-v2**（签名校验级基准），非 stwo 真证明；
   `proof_ready` 度量的是"结算任务入队 → 证明完成"的机制延迟。
2. **内存模式**（无 WAL fsync）：与既有 64×50 基线（3200 手、p99 3.5 ms）
   同口径，便于对比；挂 WAL 复测预期 p99 会抬升（fsync 承诺点）。
3. 长压测模式的 TPH 采样行中 `soft_confirm_p99_us` 字段本次为 null
   （该字段的直方图观测点在重构中改为延迟向量收集，总量 p99 见 §2——
   判定线按总量 p99 评估）；`proof_ready_p95_ms` 采样正常（恒 1 ms）。
4. 节流为全局手动节流（250 ms/手）：这是"持续活跃桌群"的受控负载口径，
   不是无限速极限吞吐测试；无限速下生成端会自我背压（队列满退避重试，
   不丢手）。
5. 本机为开发机（Apple Silicon，macOS），非隔离基准环境；数字用于机制
   验收（预算线判定），非发布级性能承诺。
