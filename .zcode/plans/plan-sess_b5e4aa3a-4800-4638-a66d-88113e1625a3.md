# 迁移 poker_zkvm 主 crate 进 zchain + 推进 P05-R 单 proof 递归 soundness

## 背景判断（诚实陈述）

- **迁移部分可完整闭合**：依赖侧极干净——poker_zkvm 的 `[workspace.dependencies]` 与 zchain 的完全逐字节重合（除 `vm-common` 已是 zchain 成员、`poker_protocol` 已是 zchain workspace dep）。`vm-common` 当前在 poker_zkvm 里写的是外部 `path = "../zchain/vm-common"`，迁入后改为 `workspace = true` 即可。
- **P05-R「全力」的可闭合边界**：文档明确把「让单 proof 递归 sound」拆为多个子缺口。我能在这一轮**机械闭合 gap #1（Merkle 空 query no-op + 伪 leaf/sibling）**，并加固 transcript 一致性守卫；但 **gap #3（从未对真实 Texas method AIR 跑过）需要 guest crate ELF，本轮「不动 guest」的约束下无法端到端验证**。因此本轮 P05-R 的诚实产出是：**让 trivial-CPU-trace 路径上的单 proof 递归做到自洽 sound，并把 fail-closed 门从「全跨 crate 禁用」收窄为「未强制非空 commitment/query 的路径禁用」**，仍不宣称对真实 method proof 已 sound。
- 不动 guest 的连带影响：poker_zkvm 的 `tests/*.rs`(3 个) 和 `benches/*.rs` 在 `[dev-dependencies]` 里依赖 `texas_poker_guest`（path = "guests/texas_poker"）并用 `CARGO_MANIFEST_DIR + guests/texas_poker/target/...` 拼 ELF 路径。**只迁 src 会让这些文件无法编译**。处理方式见下方第 4 步。

## 第 5 步：P05-R soundness 推进（gap #1 闭合，保持诚实收窄）

目标文件：`poker_zkvm/src/stwo_backend/recursive/{recursion_prover,recursion_verifier,trace_gen}.rs`。

**(a) 强制非空 commitment/query**（gap #1 核心）：
- 在 `prove_recursive` / `prove_recursive_with_fri` 入口（`if !cfg!(test)` 守卫之后）新增显式前置检查：
  - `public_inputs.l1_commitments.is_empty()` → 返回新错误 `L1CommitmentsMissing`。
  - `public_inputs.query_positions.is_empty()` → 返回新错误 `QueryPositionsMissing`。
  - `public_inputs.log_size == 0` → 返回新错误 `InvalidLogSize`。
- 这样 PoC 调用方不能再传空 input 让 `gen_merkle_path_trace` 走 no-op 分支（`trace_gen.rs:883`）。

**(b) 消除 trace_gen 的伪造 leaf/sibling**（gap #1 第二半）：
- `compute_leaf_hash`（`trace_gen.rs:951`）在 `queried_values` 为空时返回硬编码伪 hash → 改为 `panic!`（prover 内部不变式：走到这里必有真实 decommitment，因为 (a) 已挡住空 input）。
- `extract_sibling_hash`（`trace_gen.rs:977`）在 `decommitments` 为空或越界时返回 `[0;8]` → 改为 `panic!`。
- `gen_merkle_path_trace` 的 `num_queries == 0 → Vec::new()` 早退（`trace_gen.rs:883`）删除（被 (a) 挡住，不会到达，但移除死路径以防误用）。

**(c) Verifier 侧对称守卫**：`recursion_verifier.rs` 的 `verify_recursive_with_fri` 对空 `query_positions`/`l1_commitments` 同样返回 fail-closed 错误（防伪造 proof），且仍保留 `if !cfg!(test)` 的全局生产禁用。

**(d) 新增 soundness 回归测试**（加到 `src/stwo_backend/recursive/e2e_test.rs`，`#[cfg(test)]`）：
- `recursive_prover_rejects_empty_commitments`：空 `l1_commitments` → 断言返回 `L1CommitmentsMissing`。
- `recursive_prover_rejects_empty_query_positions`：空 `query_positions` → 断言 `QueryPositionsMissing`。
- `recursive_sound_e2e_nonempty_inputs`：用真实 L1 proof（`make_l1_proof`）+ 非空 commitments/query（从该 proof 提取），跑通 prove→verify，证明非空路径仍闭合。
- `tampered_commitment_fails`：把 `l1_commitments[0]` 改一字节，断言 verify 失败（证明 transcript binding 生效）。
