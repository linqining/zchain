## 目标

新增方法 `fold_with_proof`：玩家 fold 时不仅弃牌，还通过 DLEqProof（LeaveKind）剥离自己的加密层（remove pk from aggregated_pk + remask encrypted deck），并从后续 reveal 协议中彻底退出——后续解牌不需要该玩家参加。

这是 `leave_with_proof` 的"对局中"版本：`leave_with_proof` 仅在 WAITING 状态可用（局间离场），`fold_with_proof` 在下注轮可用（局中弃牌+退出协议）。

## 设计决策（已与用户确认）

1. **复用 `DLEqProof<DefaultCurve, LeaveKind>`**：fold-with-pk-removal 在密码学上就是一次 leave（剥离玩家加密层），transcript label `b"zk_leave_proof_v1"` 不变。**不修改 `poker_protocol`**。
2. **seat 状态：仅 `folded=true`**。保留 `seat.pk`（不置 identity）、保留 `seat.total_bet`（side-pot 计算）、**不设** `left_during_hand`（玩家仍可见于 side-pot 记账，只是已弃牌+退出协议）。`seat.bet` 保留（由 round 结束时 `collect_bets_to_pot` 统一收集，与普通 fold 一致）。
3. **仅下注轮可调用**（`is_betting_round()`，即 PREFLOP/FLOP/TURN/RIVER betting phase）。此时 `reveal_token_state.assignments` 为空（reveal phase 在 `check_reveal_phase_complete` 后已重置），scrub 操作天然安全。

## 具体改动

### 1. `state_machine.rs` — 新增 `apply_fold_with_proof`

位置：紧邻 `apply_leave_with_proof`（~line 1754 之后）。

```rust
pub fn apply_fold_with_proof(
    table: &mut TexasPokerTable,
    seat_index: u8,
    output_cards: Vec<ElGamalCiphertext>,
    fold_proof: DLEqProof<DefaultCurve, LeaveKind>,
    events: &mut Vec<TexasPokerEvent>,
) -> PokerL1Result<()>
```

逻辑步骤（严格对齐 `apply_leave_with_proof` + `apply_fold_internal`）：

1. **Guards**（对齐 `apply_fold_internal`）：
   - `is_betting_round(table)` —— 关键：仅下注轮可用（与 leave 互补）
   - `is_player_turn(table, seat_index)`
   - seat_index 越界校验
   - `seat.is_occupied()`
   - `!seat.folded`

2. **验证 DLEq proof**（完全复制 leave 1696-1710）：
   - `input_cts = table.deck_state.encrypted.clone()`
   - `output_cts = output_cards`
   - `player_pk = seat.pk`
   - `DLEqProof::<DefaultCurve, LeaveKind>::verify(&fold_proof, &input_cts, &output_cts, &player_pk, &mut utils::new_leave_transcript())`
   - 包在 `utils::verify_or_skip(table.config.skip_remask(), ...)`

3. **剥离 pk + 替换 deck**（复制 leave 1712-1715）：
   - `remove_pk_from_aggregated(aggregated_pk, player_pk)` → 更新 `deck_state.aggregated_pk`
   - `table.deck_state.encrypted = output_cts`

4. **Scrub 协议 pending 列表**（复制 `kick_player_internal` 2785-2790，关键：让玩家退出后续 reveal）：
   ```rust
   remove_from_pending(&mut table.shuffle_state.pending_players, seat_index);
   remove_from_pending(&mut table.shuffle_state.completed_players, seat_index);
   remove_from_pending(&mut table.reconstruct_state.pending_players, seat_index);
   for a in &mut table.reveal_token_state.assignments {
       remove_from_pending(&mut a.pending_players, seat_index);
   }
   ```
   （下注轮调用时 `assignments` 为空，循环无操作；保留以备防御性。）

5. **标记 fold**（对齐 `apply_fold_internal` 1787-1788）：
   - `seat.folded = true; seat.acted_this_round = true;`
   - `table.timestamps.betting_started_at = 0;`
   - emit `PlayerFolded { seat_index, reason: FOLD_REASON_MANUAL, round_state }`
   - **不** 置 `left_during_hand = true`，**不** 清 `seat.pk`，**不** 改 `seat.bet`/`seat.total_bet`/`seat.stack`

6. **推进轮次**（复制 fold 1800-1807）：
   - 若 `count_active_players(&table.seats) <= 1` → `end_without_showdown`（return Ok）
   - 否则 `advance_turn`
   - `table.bump_version()`

### 3. 单元测试（dispatch.rs）

- **基本流程**：2 玩家下注中 → p1 `fold_with_proof` → p1.folded=true、aggregated_pk 已移除 p1.pk、encrypted deck 已替换、reveal_token_state.assignments 中无 p1（下注轮本就为空）；p1.total_bet 保留。
- **权限校验**：非 seat player 调用应失败。
- **非下注轮拒绝**：在 WAITING/reveal phase 调用应失败（"not in betting round"）。
- **越界 seat_index**：返回错误而非 panic。
- **重复 fold 拒绝**：已 folded 的 seat 再次调用应失败。
- **last-player-standing**：fold 后只剩 1 活跃玩家 → 触发 end_without_showdown（验证 pot 分配）。

所有测试用默认 config（`skip_remask=true`），无需真实密码学。

## 不改动的部分（明确范围）

- ❌ **不修改 `poker_protocol`**（复用 `LeaveKind`，无新 marker）。
- ❌ **不修改 `poker_texas_air` 的 `MethodKind` 枚举**（保持 21，新 selector 不进 AIR prove）。
- ❌ **不修改 `vm-common` 的 `MethodInput`**。
- ❌ **不修改 `Seat` 结构体**（复用现有 `folded` 字段）。
- ❌ **不修改 `reset_for_next_hand`**（fold_with_proof 不设 left_during_hand，玩家仍参与 side-pot；下一手 reset 时 folded 清零，正常进入下一局——但注意：因为 pk 已从 aggregated_pk 移除，下一局 start_hand 会重新洗牌，玩家需重新 join_and_shuffle 或被排除。这是预期行为，与 leave 一致）。

## 资金账与不变量

- `seat.total_bet` 保留 → side-pot 计算正确（folded 玩家仍按 total_bet 参与分层）。
- `seat.bet` 保留 → round 结束由 `collect_bets_to_pot` 收集（与普通 fold 一致）。
- `aggregated_pk` 移除 player_pk → 后续 reveal token 验证不再要求该玩家（且该玩家已从 pending_players 移除）。
- `encrypted deck` 替换为 output_cts（c1 不变，c2 剥离 player mask）→ 已收集的 reveal tokens 仍有效（依赖 c1 不变性，DLEq verify 强制 `input.c1 == output.c1`）。
