## 目标

在 `texas_poker` 合约中新增方法 `request_leave_after_hand`，让玩家可在**任意时刻**（包括对局进行中）登记"下局开始前离场"的意图。当局结算（`settle_hand` / `end_without_showdown` / 超时路径）触发 `reset_for_next_hand` 时，自动踢出已登记的玩家并退还筹码。

这是在线扑克（PokerStars / GG）的 "sit out next hand / stand up" 标准模式，解决了"`leave_table` 仅在 WAITING 状态可用、而 creator/`tick` 可能立即 `start_hand` 导致玩家来不及离场"的问题。

## 设计要点

- **新增 `Seat.want_leave: bool` 字段**（默认 false）。borsh 序列化兼容（追加字段，旧对象反序列化报错需 governance 重置——与现有 `creator` 字段同样的兼容策略）。
- **新方法 `request_leave_after_hand`**：toggle 语义（再次调用取消），权限 `caller == seat.player`（与 `leave_table`/`addon` 一致）。**允许在任意 round_state 调用**（这是关键：玩家可在牌局中预约离场）。
- **`reset_for_next_hand` 强制执行**：在第三阶段（清理 stack==0 的 seat）之前，先把 `want_leave=true` 的 occupied seat 踢出（复用 `kick_player_internal` 的资金账逻辑：退 stack+pending_addon，扣 chip_pool/addon_pool，从 aggregated_pk 移除，发 `PlayerRefund` + `PlayerLeft` 事件）。
- **无需新增 AIR**：新 selector 在 `build_method_input` 返回 `None`（`prove_task=None`，与 `tick` 同模式），实际状态转换在 `reset_for_next_hand` 内完成（已有 `MethodKind::ResetForNextHand` AIR）。**不修改 `poker_texas_air` 的 `MethodKind` 枚举**（保持 21 个），避免破坏 AIR orchestrator 的 exhaustive match。

## 具体改动

### 1. `types.rs` — Seat 新增字段
- `Seat` 结构体添加 `pub want_leave: bool` 字段（注释说明语义）。
- `Seat::empty()` 初始化 `want_leave: false`。
- 更新 `state_machine.rs` 中所有 `Seat { ... }` 字面量（`apply_join_shuffle` 等）+ `types.rs` 测试中的 `Seat { ... }` 字面量。
- 更新 `Seat::status()` 注释或文档（不变动枚举本身，`want_leave` 是独立标志）。

### 2. `constants.rs` — 新增退款类型常量（可选）
- 复用现有 `REFUND_TYPE_STACK_ONLY = 0`，无需新增。

### 3. `events.rs` — 新增事件
- 新增 `LeaveRequested { table_id, seat_index, player, want_leave: bool }` 事件（toggle 上下，便于链下索引）。
- 更新模块顶部注释的事件分类。

### 4. `state_machine.rs` — 新增 + 修改
- **新增** `pub fn apply_request_leave(table, seat_index, events) -> PokerL1Result<()>`：
  - seat_index 越界校验 + `seat.is_occupied()` 校验。
  - toggle `seat.want_leave`。
  - emit `LeaveRequested { ..., want_leave: !old }`。
  - `table.bump_version()`。
- **修改** `reset_for_next_hand`：在第三阶段（清理 stack==0 的 seat）之前新增一个"清理 want_leave seat"阶段。对每个 `is_occupied() && want_leave` 的 seat：
  - 退 `stack + pending_addon`（refund_amt），扣 `chip_pool` / `addon_pool`。
  - 从 `aggregated_pk` 移除该 pk（若非 identity）。
  - `seat = Seat::empty()`。
  - emit `PlayerRefund { refund_type: REFUND_TYPE_STACK_ONLY }` + `PlayerLeft`。
- 资金账逻辑严格对齐 `dispatch_leave_table` / `apply_leave_with_proof` / `kick_player_internal`。

### 5. `dispatch.rs` — 新增 selector + dispatch 路由
- 在 `selectors` 模块新增 `pub fn request_leave_after_hand() -> [u8; 32]`。
- 加入 `selectors::all()`（22 个）。
- 新增 `RequestLeaveArgs { seat_index: u8 }`（或直接复用 `SeatIndexArgs`）。
- 新增 `dispatch_request_leave(context, table, args, events)`：`require_caller_is_seat_player` 校验 + 调用 `state_machine::apply_request_leave`。
- 在 `dispatch` 主 match 添加 selector 分支。
- 在 `build_method_input`：该 selector 返回 `None`（无 prove_task，同 `tick`）。
- 更新顶部注释（"21 method selector" → "22 method selector"）。
- 更新 `all_selectors_unique` 测试断言（21 → 22）。

### 6. 新增单元测试（dispatch.rs）
- toggle 测试：连续两次调用 `request_leave_after_hand`，第二次 want_leave 应为 false。
- 权限校验测试：非 seat player 调用应失败（与 `dispatch_fold_rejects_non_seat_player` 同模式）。
- 对局中调用测试：在 `ROUND_PREFLOP` 状态调用应成功（验证"任意时刻可预约"）。
- `reset_for_next_hand` 强制执行测试：设置 want_leave → 调用 reset → seat 被清空 + chip_pool 正确扣减 + 事件正确。
- 资金账平衡测试：join (buy_in=X) → request_leave → reset → 退款 X 后 chip_pool 回到 join 前。

### 7. 文档更新
- `mod.rs` 顶部模块说明（dispatch 21 → 22）。
- `method_kind.rs`（poker_texas_air）顶部注释保持 21（**不新增 variant**，仅说明 request_leave_after_hand 不进入 AIR prove 流程）。

## 不改动的部分（明确范围）

- ❌ **不修改 `poker_texas_air/src/method_kind.rs` 的 `MethodKind` 枚举**（保持 21 个 variant）。新方法不走 AIR prove（`prove_task=None`），实际状态转换在 `reset_for_next_hand` 内（已有 AIR 覆盖）。
- ❌ 不改动 `vm-common/src/prove_task.rs` 的 `MethodInput`。
- ❌ 不改动 orchestrator 的 exhaustive match。
